# CLAUDE.md — Project Context

## What is this project?

hello-claude-code is a hands-on learning guide that helps people who are brand
new to Claude Code (and likely new to GitHub, markdown, and agentic workflows)
become confident, agent-native product managers.

The repo itself is the product — users learn by working inside it with Claude Code.

## Repo layout

- `/` — User-facing content: README, learning modules, interactive content
- `/meta` — Builder workspace: architecture decisions, research, design, backlog
  (not part of the user experience)
- `/CLAUDE.md` — This file. Project context for Claude Code sessions.

## Principles

- **The user is a beginner.** Don't assume knowledge of git, markdown, CLI, or
  programming. Explain things in plain language.
- **Show, don't just tell.** Use rich visuals (self-contained HTML pages) where
  they help.
- **The repo is the product.** Keep the root clean and user-friendly.
- **Builder work goes in /meta.** Decisions, research, and planning stay separate
  from the learning content.
