# Hello, Claude Code

Learn to work with AI agents — starting from zero.

This project is a hands-on guide for people who are new to Claude Code, new to
GitHub, and new to the idea of collaborating with an AI agent. By the end you'll
be comfortable using Claude Code as a thinking partner for real work.

## What you'll need

- A Claude Code subscription (any plan)
- A GitHub account
- A willingness to experiment

## Getting started

> **This project is under active development.** Check back soon for the first
> learning modules. If you're here early, feel free to open the repo in Claude
> Code and start exploring — that's the whole idea.

## How this works

You learn by *doing things inside this repo* with Claude Code as your guide.
The repo contains learning content, interactive challenges, and rich visual
explainers — all designed to be experienced through Claude Code itself.
